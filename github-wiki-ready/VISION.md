## How to complete this page

Write in English. Replace prompts with actual findings; keep unresolved questions visible. Use short paragraphs, tables and diagrams only when they improve understanding. Label evidence, assumptions and proposals separately.

## Problem statement

**Required work:** Identify observable limitations of current workflows, with examples; avoid universal claims about existing tools.

**Expected output / writing format:** Problem / affected user / observed evidence / impact.

**Working content:** _To be developed by the owner and contributors._

## Vision

**Required work:** Describe the desired future workflow in user language.

**Expected output / writing format:** One paragraph plus before-and-after scenario.

**Working content:** _To be developed by the owner and contributors._

## Differentiation

**Required work:** Record candidate differentiators such as controlled execution, evidence and experience; compare only using evidence.

**Expected output / writing format:** Claim / alternative / evidence required / related research.

**Working content:** _To be developed by the owner and contributors._

## Success goals

**Required work:** Define what would make the project valuable and what would falsify each claim.

**Expected output / writing format:** Goal / observable indicator / validation link.

**Working content:** _To be developed by the owner and contributors._
