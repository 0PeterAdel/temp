## Work package
Stable ID / design page and agreed version / requirement IDs / owner role / expected deliverable / dependencies / exclusions.

## Candidate Jira item
- **Type:** Epic / Story / Task / Subtask / Bug / Research spike (per configured project).
- **Summary:** action + outcome.
- **Description:** why, scope, links to design and decision.
- **Acceptance criteria:** observable behavior or research output, including negative case where relevant.
- **Dependencies:** linked work packages or issues.
- **Reviewer / test evidence:** different person, evidence expected.
